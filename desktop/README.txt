PING OPTIMIZER 0.3 — WINDOWS TECHNICAL PREVIEW

This preview includes the desktop interface, continuous detection for supported
running games, real public-edge connection diagnostics, a reversible session
power plan, and automatic restoration when the detected game closes.

The production relay network is not active in this build. It does not reroute
game traffic or claim to lower ping.

Run Ping Optimizer.exe to start.

Windows may show an unknown-publisher warning because this preview has not yet
been code signed. Do not redistribute it as a production release.
