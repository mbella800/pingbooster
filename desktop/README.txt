PING OPTIMIZER 0.4 — WINDOWS TECHNICAL PREVIEW

This preview includes the desktop interface, continuous detection for supported
running games, real public-edge connection diagnostics, a reversible session
power plan, and automatic restoration when the detected game closes. The FPS
Boost foundation reports live Windows CPU and RAM load plus GPU utilization
when Windows exposes it. Its before/after check is a system-load comparison,
not a fabricated in-game FPS result.

Easy Lobby is a regional latency guide. It compares direct connections to
regional public endpoints and recommends the best measured network region. It
does not alter matchmaking, spoof account location, or promise easier players.

The production relay network is not active in this build. It does not reroute
game traffic or claim to lower ping.

Run Ping Optimizer.exe to start.

Windows may show an unknown-publisher warning because this preview has not yet
been code signed. Do not redistribute it as a production release.
